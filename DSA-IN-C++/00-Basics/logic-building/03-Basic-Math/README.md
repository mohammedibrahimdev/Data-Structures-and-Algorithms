# Basic Math

This section focuses on building a strong mathematical foundation for problem solving, Data Structures & Algorithms, and Competitive Programming.

## Why Learn Basic Math?

Many programming problems rely on mathematical observations rather than brute force solutions.

This section helps you learn:

- Prime Numbers
- Factors and Divisors
- GCD & LCM
- Powers
- Number Properties
- Number Systems
- Mathematical Optimization

These concepts frequently appear in Competitive Programming platforms such as Codeforces, CodeChef, and LeetCode.
